Nothing is preconfigured — no endpoint, model, or key ships with the repo. Point this at any OpenAI-compatible endpoint (OpenAI proper, Groq, OpenRouter, Ollama, LM Studio…). Without one you still get the offline notes.

Stored in this browser’s localStorage, forwarded through your local server, never written to disk or logged. Close the tab and it stays here; clear site data and it’s gone.

MCP server

Runs Onboarder as a Model Context Protocol server, so any AI agent or harness on this machine can ask it about a repository — its structure, architecture, health, security, history, and every file in it — by talking to it. The server reads repositories and never writes to them.
